## Before you publish these

Screenshots bake in whatever is on screen, so:

- Prefer a **sandbox tenant** with **generic** group/policy names (e.g. "Corp - Windows - Baseline"), or **blur/redact** real names before committing.
- Double-check no tenant identifiers, user names, or serial/device IDs are visible.
- PNG, roughly 1600px wide is plenty; the README scales them to page width.
